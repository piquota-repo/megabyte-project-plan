Phase Summary
⚙️ Phase 0 — Foundation Months 1–4

Azure Landing Zone setup, CI/CD pipelines, SSO via Azure AD (PKCE), VNET & NSG design, Elastic Pool provisioning, peripheral hardware audit (Cashiering scanners/printers), and environment sign-off.

🏗️ Phase 1 — Tier 1 Delivery Months 5–12

Assessor module (358 tables, 38.9M rows) and Taxroll (149 tables, 14.2M rows). First .NET 8 APIs go live. React SPA scaffold with 10 reusable UI templates. Migration Factory delivery model activated. Automated scaffolding engine for DTO & API controllers.

📦 Phase 2 — Tier 2 Expansion Months 13–18

TOT (38 tables) and COB (26 tables) modules. Shared services: Search (Redis), Address (GIS), Reporting (Power BI / SSRS replacing Crystal Reports). UI Design Freeze. Multi-tenant row-level security hardening.

🏁 Phase 3 — Finalization Months 19–24

CBT/WIS cleanup & merge into Tax service (~51 non-functional screens retired). Full data migration, UAT, parallel run wind-down, legacy WinForms UI shutdown. DR/RTO/RPO go-live validation.
